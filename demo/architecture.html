Remote server HTTP + OAuth

webcmd's browserless tier — runs on any cloud host
  • Imports web/fetch in-process
  • Tier escalation → real browser fingerprint
  • SSRF-safe proxy · readability extraction
  • Connects to claude.ai via OAuth 2.1
  • No filling — needs your browser

Why web/fetch works in the cloud — webcmd's own manifest declares it "browser": false, "clientOwned": true, so the remote server calls the same func() the CLI runs — minus the process spawn.

Every eligibility response returns fetched_via: "webcmd web/fetch (tier: plain)" — the dependency is verifiable, not claimed.
